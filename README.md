# Quantum Stone Capital — HFT AI Brain Bot

A multi-layer, multi-agent algorithmic trading system that synthesizes
75+ trading resources into a debate-driven decision architecture.

## Architecture

LAYER 0: DATA          — OHLCV, tick, order book, intermarket, PIT
LAYER 1: ACCOUNT RULES — CCP-equivalent + prop firm + personal rules
LAYER 2: PRICING       — FRM, CAPM, Elliott, Bayesian, bootstrap
LAYER 3: STRATEGIES    — 500+ formalized setups across 75+ resources
LAYER 4: RISK          — Hedge ratios, VaR, deflated Sharpe, R-Cubed
LAYER 5: EXECUTION     — 7+ order types, Kyle lambda, TWAP
LAYER 6: DEBATE        — Bull/Bear/Hold + Risk/Strategy/Execution Jurors
LAYER 7: MAIN BRAIN    — Routing, ML selection, EMH awareness

## Constraints

- No Node.js
- No Docker
- GitHub commits at every phase
- Python stack
- CPU-only PyTorch by default (override if GPU available)
